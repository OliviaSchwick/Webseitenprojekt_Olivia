Projektidee:
Ich möchte eine Website über Frank Ocean erstellen. Meine Website wird ein modernes Design haben und über Frank Ocean Informieren.

Zweck:
Euch Frank Ocean vorzustellen und euch Informationen über ihn zu geben.

Strucktur und Seitenaufbau:
Die Website besteht aus einer einer einzigen Seite, die in mehrere klar getrennte Abschnitte geglidert ist. Durch sanfte Scroll-Animationen gelangt man von einem Bereich zum nächsten. Der Hintergrund soll Orange sein mit Weissen Details. Oben zentriert in grosser Schrift soll "Frank Ocean" stehen. Darunter ein orangener Butten mit der Aufschrift: "Steckbrief", der Button soll aufleuchten, wenn man mit der Maus drauf geht. Darunter kommen weitere Buttons mit je einer anderen Aufschrift: "Wo ist Frank Ocean?" und noch weitere.

Farbkonzept und Design:
- Farben: Orange für Hintergründe als Haubtfarbe. Sekundärfarbe soll Weiss sein für Textflächen und für die Buttons
- Schriftarten: Eine moderne Schrift für Fliesstexte. Für die Buttons soll jeweils die Schriftart (oder eine ähnliche) eines Albums von ihm sein.
- Designstil: Das Design soll vorallem an seinen bekanntesten Alben inspiriert sein.
