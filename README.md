# Websitenprojekt Olivia:

# Projektidee

Ich möchte eine Website über Frank Ocean erstellen. Meine Website wird ein modernes Design haben und über Frank Ocean Informieren.

# Zweck

Euch Frank Ocean vorzustellen und euch Informationen über ihn zu geben.

# Strucktur und Seitenaufbau

Die Website besteht aus einer einzigen Seite, die in mehrere klar getrennte Abschnitte geglidert ist. Durch sanfte Scroll-Animationen gelangt man von einem Bereich zum nächsten. Der Hintergrund soll Orange sein mit weissen Details. Oben zentriert in grosser weisser Schrift soll "Frank Ocean" stehen. Darunter sollen in Form von Kästchen, die Weiss sein sollen verschiedene Abschnitte mit anderen Themen kommen. Diese weissen Kästchen sollen in Orangener Schrift Zentrierte Überschriften haben wie z.B. "Steckbrief" oder "Awards". Mit sanften Scroll-Animationen soll man mehrere Kästchen bekommen.

# Farbkonzept und Design:
- Farben: Orange für Hintergründe als Haubtfarbe. Sekundärfarbe soll Weiss sein für Textflächen und für die Kästchen
- Schriftarten: Eine moderne Schrift für Fliesstexte. Für die Buttons soll jeweils die Schriftart (oder eine ähnliche) eines Albums von ihm sein, wenn dies möglich ist. Wenn nicht und die Schriftart zu sehr abschweifen sollen auch sie eine moderne Schrift haben.
- Designstil: Das Design soll vorallem an seinen bekanntesten Alben inspiriert sein. Der Grund weshalb ich mich für einen orangenen Hintergrund und weisse Schrift entschieden haben ist durch sein Album: "Channel Orange" inspiriert.

# Zeitplanung:
- Woche 1: Ideensammlung
- Woche 2: Planung beginnen (Projektidee, Zwech, Strucktur, Seitenaufbau, Farbkonzept, Design)
- Woche 3: Einführung in HTML und Informationen suchen
- Woche 4: Planung fertigstellen und abgeben. Website gestalten mit CSS.
- Woche 5: Kästchen und Animationen einfügen
- Woche 6: Dokumentation fertigstellen. Abgeben.
